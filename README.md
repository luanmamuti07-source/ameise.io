# Ameisenreich

Ein Ameisen-Strategiespiel im Browser. Alles steckt in einer Datei: `ameisenreich.html`. Einfach im Browser öffnen.

## Was drin ist

- Baue mit Räumen (Brutkammer, Vorratskammer, Kriegerquartier, Kaserne, Pilzgarten, Wachkammer)
- Getrennte Plätze für Sammlerinnen und Armee
- Eigenes Futter pro Bau, Logistik zum Verschieben von Futter und Ameisen
- Ausbildungs-Warteschlange pro Bau
- Sechs Ameisenarten mit eigenen Fähigkeitsbäumen und einmaligen Spezialisierungen
- Legionen, Überfälle, neue Baue gründen
- Ereignisse: Riesenkäfer, Regenwürmer, Eis, Picknick, Regen, Jagdspinne, Ameisenlöwe, Riesenschuh
- Nebel des Krieges
- Ameisen- und Bau-Skins für Bernstein

## Steuerung

| Taste | Aktion |
| --- | --- |
| Ziehen / WASD | Karte bewegen |
| Mausrad | Zoom |
| Klick auf Bau | Bau-Menü |
| E | Evolution |
| L | Logistik |
| R | Legion ausheben |
| 1–5 | Legion wählen, dann auf die Karte klicken |
| H / X | Legion heim / auflösen |
| B | Nächsten Bau öffnen |
| Leertaste | Kamera zentrieren |
